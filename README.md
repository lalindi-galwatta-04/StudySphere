# 🌟 StudySphere – Student Productivity App

**Study smarter. Stay organized. Achieve more.**

StudySphere is an Android application designed to help students organize their academic activities, manage assignments, track important dates, and build productive study habits.

The application is developed using **Kotlin** and **Jetpack Compose**, with a focus on providing a simple and user-friendly experience.

## ✨ Features

### 📚 Assignment Management
- Add and manage academic assignments.
- Organize assignments by subject.
- Set assignment deadlines and priorities.
- Update and manage assignment progress.

### 🔔 Smart Reminder System
- Create custom reminders.
- Receive automatic reminders for upcoming assignments.
- Manage examination reminders.
- Get notifications for important academic activities.

### 🍅 Pomodoro Timer
- Use focused study sessions.
- Organize study time with breaks.
- Build consistent study habits.

### 📅 Academic Calendar
- View important dates.
- Keep track of upcoming academic activities.
- Stay organized with a calendar-based view.

### 📝 Additional Productivity Tools
- Manage study-related activities.
- Keep important academic information organized.
- Access productivity features from one application.

## 🚀 Getting Started

To run StudySphere locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/lalindi-galwatta-04/StudySphere.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Build and run the application.
